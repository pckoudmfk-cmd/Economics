# Грамоты и дипломы МФК

Шаблон сохраняет шапку колледжа, фон, ленту, подпись и должность директора
(А.Г. Хачатрян). Меняется только смысловой блок и дата.

## Структура
- `template.html` — шаблон листа A4; открывается в браузере, текст правится щелчком, печать в PDF кнопкой.
- `render.js` — пакетная выгрузка: `node certificates/render.js certificates/data/<файл>.json`
  (с `PNG=1` дополнительно сохраняет превью). Результат в `certificates/out/<файл>/`.
- `data/*.json` — данные награждённых: блок `common` (общие поля) и массив `items` (по записи на грамоту).
- `assets/` — подложка, подпись, мотив «сбережения», шрифты.
- `tools/build_assets.py` — пересборка подложки и подписи из исходного скана.

## Поля записи
| поле | смысл | по умолчанию |
|---|---|---|
| `docType` | ГРАМОТА / ДИПЛОМ | ГРАМОТА |
| `degree` | степень, напр. «I степени» | пусто |
| `lead` | «Награждается» | Награждается |
| `name` | ФИО | — |
| `role` | «студент группы …» | студент группы ______ |
| `org` | строки об организации | МФК Финансового университета |
| `reason` | за что; `<small>` даёт строку номинации мельче | — |
| `date` | дата | — |
| `motif` | `false` убирает мотив «сбережения» | true |
| `file` | имя PDF-файла | ФИО |
